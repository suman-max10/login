# Glowing Animated Login Form

A modern, animated login UI built with only HTML and CSS.

# Live link 
->> https://suman-max10.github.io/login/

## Preview

This project displays a centered login card with:
- Rotating glowing border effects
- Hover expansion animation
- Styled username/password inputs
- Sign in button glow interaction

## Project Structure

- `index.html` - Markup for the login form
- `style.css` - Styles and animations

## How to Run

1. Open `index.html` in your browser.
2. Hover over the login box to view the full animated form effect.

## Notes

- No build tools or dependencies are required.
- Font Awesome is loaded via CDN for icons.
- Google Fonts is used for typography.
